# 判断边界审核与第二组正式配置

2026-10-28。已读取第一轮验证错误，因此本轮属于验证反馈驱动的开发，不能称为独立泛化验证。

## 审核结论

对132条训练状态的目标、资源、结果及标注依据进行了作者复核。没有确认必须翻转的标签；保留全部原始标签，不通过修改验证答案提高成绩。独立人工审核仍pending。

更明显的问题是覆盖不对称：已有多条“用户未提供选择/私有上下文→clarify”，而选择记录已给出、指代唯一、可采用默认维度的正例较少。不能仅凭首次训练退化证明这是唯一原因，本轮将其作为待验证假设。

| 边界 | 应澄清 | 可执行 |
| --- | --- | --- |
| 用户指定选择 | 多个对象，选择记录缺失 | 选择明确写在goal或results中 |
| 指代 | 单数指代对应多个对象 | 只存在一个对象；两篇对比恰有两篇 |
| 搜索要求 | 连主题也无法确定 | 主题已知，未给年份/篇数可默认 |
| 分析要求 | 只有孤立标题，没有动作 | “帮我读懂”已是动作，未列细节可概述 |
| 对比要求 | 所选对象无法确定 | 对象确定，未给维度可用常见维度 |
| 缺少论文 | 所指私人文件或未明确对象必须由用户给出 | 明确题名可搜索，已有候选可下载 |
| 完成状态 | 不是澄清条件 | 只在目标确实交付或不能继续时finish，其他结果不能代替 |

新增36条、18组成对状态，覆盖选择记录缺失/具备、单数/复数指代、可默认参数、全文准备程度与目标完成状态；增加不同主题与中英文表达，存放于 `data/boundary/`。并非给验证题换名后的训练拷贝，原始132条逐字保留。合计168条，各类26–30条。验证/测试候选文件哈希不变，跨集合文本近邻阈值0.30未命中；这不保证语义独立。同族成对状态不能当作统计独立样本。

## 第二组预登记

- 仅更换训练数据为168条边界补充集，提示词、输出契约、原始基座和推理设置不改。
- 从原始基座重新开始，不续接第一次适配器。沿用NF4/BF16、LoRA rank8/alpha16/dropout0.05、q/k/v/o、学习率2e-5、batch1累积4、长度512不截断。
- 固定3轮，每轮42次更新，共126次。每轮验证，命中率优先、Macro-F1其次、同分选较早轮，与第一组相同。
- 样例数增加使每轮更新数增加，因此不能将变化完全归因于数据内容；不是严格的单变量消融实验。
- 独立进程重载选中检查点，检查36条输出一致性；保留原始模型、第一组和本组各轮结果。
- 本轮为计划中第二组正式配置。无论是否达到指标，都不自动启动第三组，不触碰测试候选或接入业务。
- 目标仍按总计划，不降低标准。验证集已经反复用于开发，若成绩改善也只能报告开发集改善。

运行目录：`outputs/router/formal-20261028-02/`。3轮126次更新已完成，训练循环合计455.36秒，峰值分配4.93GiB、预留5.34GiB，无OOM。独立重载通过：适配器张量哈希及36条原始输出完全一致。重载推理P50/P95为0.967/1.094秒，峰值分配3.54GiB、预留4.84GiB；计时受机器状态影响，不单凭两次耗时差异判断性能收益。47项离线检查通过，无新增依赖。原始数据与每轮产物保留，不覆盖第一组。

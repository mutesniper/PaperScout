## 三轮训练结果

固定171次更新已完成，训练循环共641.92秒（不含加载和逐轮验证），峰值分配约4.93GiB、预留5.37GiB，无OOM。三轮平均loss为0.4398、0.1524、0.0887。训练损失下降不等于泛化改善。

独立进程重载通过：全部36条原始输出及适配器张量哈希一致。与原始基座相比修正3题、退化1题，净增2题（5.56个百分点），但其他门槛未通过。原始基座本次复测仍29/36。

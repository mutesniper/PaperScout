## 错误分布

| 动作 | 训练集召回 | 验证集召回 |
| --- | ---: | ---: |
| search | 11/14 | 4/6 |
| download_pdf | 8/14 | 5/6 |
| answer | 11/14 | 6/6 |
| compare | 14/14 | 6/6 |
| finish | 9/14 | 5/6 |
| clarify | 2/14 | 3/6 |

compare召回高不代表对比决策可靠：模型也把缺少全文、需要澄清和对比额度为0的状态错误选成compare，导致训练集compare精确率仅14/26。

已核查的主要问题：

1. **忽略资源前置条件**：目标是比较两篇，但候选尚未下载/第二篇未找到，就直接compare；目标B尚未导入，却对已有A选择answer。
2. **忽略预算或取消**：训练集9条、验证集1条选择了allowed_routes之外的动作。输出计错并由现有解析器拒绝，不能因JSON合法而放行。
3. **澄清不足**：缺少指代对象、外部选择或任务上下文时，直接搜索、回答或对比。
4. **进度误判**：已完成第一项不代表整个任务完成；也出现重复处理已完成内容的情况。

训练集分数低于验证集不能解释为过拟合——本次尚未训练。两组任务构成和措辞不同；验证集部分目标文字直接说明资源/进度，而训练集中一些状态信息只存在结构化字段。后续要保留这类反事实状态对照，不能仅优化关键词。

## 结论与后续

4B量化推理在本机可运行，但当前验证路由命中80.56%低于计划90%目标，并存在非法动作，尚不适合替换现有Agent决策。推理显存足够也不能直接证明训练显存足够。

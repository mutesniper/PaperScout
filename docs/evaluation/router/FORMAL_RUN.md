# 正式路由训练：配置与结果

## 预先固定的实验规则（2026-10-28）

本轮只执行一组配置，先登记再训练，不根据测试候选集调参，不自动部署。

- 从原始Qwen3-4B-Instruct-2507开始，不加载短试跑adapter。
- 使用 `data/targeted/train.jsonl` 的132条数据，保留原36条验证和120条测试候选；仅验证集用于检查点选择。
- NF4双重量化、BF16计算、LoRA rank8/alpha16/dropout0.05，q/k/v/o投影。冻结基座，仅路由JSON与EOS参与损失。
- 学习率固定2e-5，AdamW、weight decay 0、梯度裁剪1；batch1、累积4、梯度检查点、长度512、不截断。
- 训练3轮，每轮33次更新，共99次。种子20261028，逐轮使用seed+epoch确定性打乱；保存全部样例顺序和步日志。
- 每轮保存adapter并在相同36条验证样例上评分；优先命中率，再Macro-F1，同分选较早轮。所有错误保留在分母，不修复模型输出后再评分。
- 本次重新评估无adapter基座，使用与适配器相同的PEFT kbit准备（非量化参数转FP32）、提示、量化与贪心解码，避免数据类型差异混入收益。旧基线29/36仍保留。
- 选中检查点用独立进程重载，核验张量哈希及全部36条验证输出。候选集不评分；云端调用0。
- 达标规则沿用[总计划](../../plans/FINETUNING.md)：命中≥90%、Macro-F1≥0.90、每类召回≥80%、schema≥99%、无非法动作、过早结束≤2%、命中较基座增加≥5个百分点。验证用于选模，小样本成绩不是独立测试或Agent闭环成绩。

## 运行与结果

运行目录：`outputs/router/formal-20261028-01/`。三轮99次更新完成，训练循环合计365.22秒，峰值分配4.93GiB、预留5.36GiB，无OOM，损失和梯度均有限。独立进程重载通过：适配器张量哈希及全部36条原始输出一致。44项离线测试通过，验证/测试候选文件哈希不变。

本次基座复测P50/P95为0.825/0.907秒；选中适配器独立重载后为0.903/0.997秒，推理峰值分配3.54GiB、预留4.84GiB。计时均含一次预热后的逐条生成，受机器负载影响；不将旧基线约0.402秒与本次耗时直接解释为训练导致的差异。各轮进程内评估保留了训练器分配，显存不用于独立推理比较。

原始产物包括 `preregistered.json`、`base-validation.json`、各轮 `order.json`/`steps.jsonl`/`training.json`/`validation.json`/`adapter/`、`result.json`、`selected-reloaded-validation.json`、`reload_check.json` 及 `comparison.json`。比较脚本：`python -m training.router.compare_formal outputs/router/formal-20261028-01`。权重和原始报告位于Git忽略目录；本页保留可提交的结果摘要。

## 失败分析与边界

- 相较基座修正4题，同时退化6题；其中5条退化是原本可搜索/问答/对比的请求被改为澄清，另1条是可问答请求被提前结束。这是观察到的行为，不把原因武断归为训练不足或过拟合。
- 下载、结束与澄清召回改善，代价是问答和对比退化；当前训练未学稳“真正缺信息”和“已有信息足够”的分界。
- 三轮平均训练loss为0.5639、0.2380、0.1207，下降没有转化成超越基座的验证成绩。
- 命中≥90%、Macro-F1≥0.90、每类召回≥80%、过早结束≤2%、收益≥5个百分点均未达到；schema和本验证集动作可用检查通过，不代表所有权限边界均已验证。
- 验证集已用于选择检查点；数据为相关联的合成场景，独立人工审核待完成，不报告独立测试成绩、统计显著性或Agent闭环收益。
- 未评分120条测试候选，没有云端调用，没有修改应用默认模型。此次只使用一个正式配置，不自动追加另一轮训练。

下一步先审核澄清与可直接执行场景的训练标签及覆盖，考虑补足跨主题、跨表达的成对状态。若设计第二组配置，必须先登记；不把本次验证错误直接复制为训练题，也不反复刷验证集当泛化能力。

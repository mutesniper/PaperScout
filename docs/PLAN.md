# PaperScout 项目计划

## 目标

展示 AI 应用工程能力：从研究想法发现论文，明确获取状态，逐步扩展到有证据的阅读和问答。先完成云端大模型版本，小模型留在后续阶段。

## 第一版：云端大模型

1. **检索闭环（本次）**：Vue + FastAPI；两个真实来源；可编辑检索计划；规范化与保守去重；全文状态依据；SQLite 缓存和历史；超时、取消、限流、部分失败；独立模型接口。
2. **阅读闭环**：合法公开 PDF 获取与上传；解析章节和页码；按章节总结；区分摘要总结与全文总结；可追溯证据。
3. **RAG 问答**：独立 Embedding 接口；FAISS；来源及章节过滤；引用核验；没有证据时说明不足。
4. **Agent 编排**：LangGraph 主 Agent；查询改写、全文查找、补充阅读；状态持久化；有界工具调用与成本预算；将文献内容视为不可信资料。
5. **交付**：收藏、Markdown 导出、固定样本评测、Docker、演示和复现说明。

每阶段运行验收后再继续；不把后续功能标记为已实现。生成模型与 Embedding 模型分别配置。

## 后续：小模型

1. 选择结构化检索规划作为首个任务，制作并人工检查样本。
2. 划分独立测试集，避免相似任务泄漏。
3. 在 8GB 显存条件下优先尝试 1B–1.5B 指令模型 QLoRA。
4. 保存训练参数、数据说明、适配器和训练日志。
5. 增加本地模型适配器，显式选择云端、本地或混合模式；按模型能力限制任务。
6. 同一测试集比较基础小模型、微调小模型与云端模型：格式正确率、条件提取、检索质量、延迟、资源与成本。

不假设微调必然提升性能，不静默回退云端。

## 可选扩展

按实际需求增加 MCP、多 Agent、OCR、混合检索和重排序。Agentic RL 不属于当前交付范围。

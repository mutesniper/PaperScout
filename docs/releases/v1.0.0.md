# PaperScout v1.0.0

2026-10-28 · 应用标签：`paperscout-v1.0.0`

PaperScout 是面向本地单用户的论文研究工作台。本版本将论文发现、全文摘要、证据问答、单 / 多 Agent 和可选本地微调路由整理为可运行、可展示的应用交付。

## 主要功能

- 自然语言检索计划，arXiv / Semantic Scholar 多来源搜索、去重、RRF 融合和本地排序。
- 公开 PDF 下载与本地上传、全文摘要、附原文证据和 PDF 页码的 RAG 问答、2～5 篇论文对比。
- LangGraph 单 Agent 与多角色协作，任务历史、取消、调用预算和失败状态处理。
- MCP stdio 工具接口、参考文献生成、Markdown 导出、Docker Compose 启动。
- 单 Agent 可切换本地 QLoRA 工具路由；独立训练、分层评测、适配器恢复和实验报告。

## 获取与启动

在本 Release 的 Assets 中下载 GitHub 自动生成的 **Source code (zip)**，或克隆固定版本：

```bash
git clone --branch paperscout-v1.0.0 https://github.com/mutesniper/PaperScout.git
cd PaperScout
```

Windows PowerShell 中使用 Docker 启动：

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
# 编辑 .env，配置生成模型服务，再执行：
docker compose up --build -d
```

打开 `http://localhost:8080`。本地开发及完整配置见[本版本 README](https://github.com/mutesniper/PaperScout/blob/paperscout-v1.0.0/README.md)；Docker 持久化数据与本地开发数据分开，详见[启动与演示](https://github.com/mutesniper/PaperScout/blob/paperscout-v1.0.0/docs/guides/DEMO.md)。

生成模型需要自行配置 `LLM_BASE_URL`、`LLM_API_KEY` 和 `LLM_MODEL`。Embedding 可选，三项配置全部留空时采用关键词检索；Semantic Scholar 密钥也可选。真实云端调用按所用服务计费，应用不附带服务凭据。

## 本地路由与适配器

应用默认采用云端模型。本地路由为单 Agent 的可选实验模式，只选择下一步操作，工具参数与研究内容仍由云端生成，多 Agent 继续使用云端决策。

- [当前适配器 router-v1.0.0](https://github.com/mutesniper/PaperScout/releases/tag/router-v1.0.0)：对应第三组第 3 轮训练，已接入本地实验路由。
- [独立候选 router-v1.1.0-experimental.1](https://github.com/mutesniper/PaperScout/releases/tag/router-v1.1.0-experimental.1)：单独发布供复现，未替换当前路由。
- [本地路由启动](https://github.com/mutesniper/PaperScout/blob/paperscout-v1.0.0/docs/guides/LOCAL_ROUTER.md)与[适配器恢复](https://github.com/mutesniper/PaperScout/blob/paperscout-v1.0.0/docs/guides/ROUTER_RELEASE.md)。

应用源码下载不包含基座权重、适配器、本地论文或运行数据库。使用本地路由时需另行准备固定版本基座与适配器；日常云端模式无需下载模型。

## 使用范围

- 当前面向本地单用户使用，未提供公网多用户认证与隔离。
- 本地小模型仍有路由判断边界，保持实验标注；Docker 跨 WSL 连接本地路由服务尚未验收。
- PDF 依赖可提取文本，未提供扫描件 OCR；引用匹配不能保证生成结论全面或推论完全正确。
- 模拟研究任务的 19/20 成绩属于离线评测，与真实论文任务的成功率分开记录。
